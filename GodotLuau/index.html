What is GodotLuau?

The Roblox API, on top of Godot

GodotLuau is a C++ GDExtension that embeds the official Luau interpreter in Godot and rebuilds the Roblox architecture on top of it: game, the services (Workspace, Players, Lighting, ReplicatedStorage…), LocalScript, ServerScript and ModuleScript, Humanoid, the R6 avatar, RemoteEvents, the task library and Roblox-style GUI.

You write game logic the way you already do, with PlayerAdded, Touched, FireServer or task.wait, and Godot takes care of rendering, physics, exporting and platforms.

Built with

  • C++
  • Luau
  • Godot 4
  • godot-cpp

What it is

  • An independent reimplementation of the most used Roblox API, on top of two open technologies: Godot and Luau.
  • A way to take your Luau knowledge and your scripts to a free engine that exports to many platforms.
  • Open source under the MIT license, with every bundled license included in the package.

What it isn't

  • A Roblox emulator or client: it never connects to Roblox servers.
  • A way to run your Roblox game as is: the API is big, but not complete.
  • A way to download Roblox assets: meshes, textures and sounds live on Roblox's servers, not inside the .rbxl file.

Features

Everything that comes with it

The pieces of Roblox Studio you use every day, rebuilt on Godot.

Roblox structure

A RobloxGame3D or RobloxGame2D root builds the whole service tree the first time you open the scene: Workspace with its Baseplate, Players, Lighting, ServerScriptService, StarterPlayer and the rest.

Scripts like in Studio

LocalScript, ServerScript and ModuleScript nodes create their own .lua file, editable inside Godot with Roblox Studio colors. Press F5 and they run top to bottom.

Characters and physics

R6 avatar with classic animations, StarterCharacter, Humanoid, constraints and BodyMovers, with Jolt physics tuned to Roblox's scale.

Roblox-style GUI

ScreenGui, Frame, TextLabel, TextButton, ImageButton, ScrollingFrame, BillboardGui and SurfaceGui, with UICorner, UIListLayout, UIStroke and UIGradient.

Import .rbxl places

Bring in a place saved from Studio: the full tree, properties, CFrames, colors, GUI, the source of every script, tags and attributes. Nothing is dropped.

Real multiplayer

Dedicated server, Direct Connect, RemoteEvents over the network and server-authoritative replication, plus a coordinator that opens worlds like Roblox does.

Lighting

ClockTime, TimeOfDay, fog, an automatic day/night cycle, presets, and Technology mapped to Godot's real graphics quality.

Autocomplete and AI

Suggestions that know your scene (workspace. lists your real children), inline syntax errors, and the optional LuauIA autocomplete models.

Updater and settings

The GodotLuau Config panel (English, Spanish and Portuguese) checks GitHub, downloads the package, verifies its SHA-256 and restarts the editor. In game, Esc opens the Roblox-style menu.

Four ways to play together

1

Local test

Open 1 to 8 windows from the editor plus a Server View window, like Studio's test mode.

2

Dedicated server

Start a server on your LAN or on the Internet and connect the clients by IP with Direct Connect.

3

Coordinator and worlds

Roblox-style matchmaking: players join without typing an IP and new worlds open by themselves.

4

Listen server from Luau

One player hosts the game from a script and the rest join them.

Requirements

  • Godot 4.3 or newer (it's developed on Godot 4.6 and 4.7).
  • Windows x86_64 or Linux x86_64.
  • Python 3, only if you want to use the new-project wizard in tools/.

macOS and other systems

There are no precompiled binaries for macOS yet. You can build it from source with SCons; the steps are in the README.

Add it to your project

  1. Download and unzipUnzip the package into the root of your project. It contains godot_luau.gdextension, the GodotLuau folder (binaries, icons, assets, shaders and default scripts) and addons/GodotLuauUpdater.
  2. Open the projectGodot loads the extension on startup. If the project was already open, restart Godot once.
  3. Turn on the pluginEnable GodotLuau Config in Project › Project Settings › Plugins if it isn't on already.
  4. Add the root nodeAdd a RobloxGame3D (or RobloxGame2D) node as the root of the scene and save it. The whole Roblox structure appears by itself.
  5. Write your first scriptRight-click ServerScriptService › Add Child Node › ServerScript, write Luau and press F5. In game, Esc opens the menu with the players and their ping, graphics quality, max FPS, volume and camera sensitivity.

Starting a brand new game?

Clone the repository and run the wizard. It asks for a name, 3D or 2D and a folder, and writes a complete Godot project with the extension, the icons, the plugin already enabled and a RobloxGame root scene.

Terminal
git clone --recursive https://github.com/Pimpoli/GodotLuau
cd GodotLuau
python tools/nuevo_proyecto.py

Updates

Changelog

GodotLuau updates itself from the GodotLuau Config panel inside Godot: it compares versions with GitHub, downloads the package, verifies its SHA-256 and restarts the editor. If an update goes wrong, you can go back to the previous version.

Limits

What it can't do yet

The API is big, but it's not all of Roblox. These are the known limits before you start a project with it.

Known limitations

  • One VM per script: a ModuleScript required by two scripts doesn't share state between them.
  • DataStoreService saves to local JSON files, not to the cloud.
  • Very large part counts (tens of thousands) work, but they aren't batched yet.
  • XML places (.rbxlx) can't be read, and rbxassetid:// content can't be downloaded.
  • Precompiled binaries only for Windows and Linux x86_64; macOS needs a source build.

Online mode and security

  • Self-hosted networking only: no relay, no NAT traversal, no accounts and no official server browser.
  • There's no server authentication or anti-cheat yet.
  • The coordinator and its worlds must run on the same machine, and every world port has to be reachable.
