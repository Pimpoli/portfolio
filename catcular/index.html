How to install

Install it step by step

Android asks for a couple of confirmations because the APK doesn't come from Google Play.

  1. Download itIf Chrome asks, tap Download anyway.
  2. Open the APKWhen it finishes, open the CatCular APK from the notification or from Downloads.
  3. Allow the sourceIf your phone says it can't install apps from this source, tap Settings, turn on Allow from this source and go back.
  4. Install itTap Install. If Play Protect warns you, tap More details and then Install anyway.

Already have CatCular from Google Play?

Uninstall it first: Android won't install this one on top of it.
