How to install

Install it step by step

Pick your system. It takes a minute.

  1. Download itIf Chrome asks, tap Download anyway.
  2. Open the APKWhen it finishes, open the CatCular APK from the notification or from Downloads.
  3. Allow the sourceIf your phone says it can't install apps from this source, tap Settings, turn on Allow from this source and go back.
  4. Install itTap Install. If Play Protect warns you, tap More details and then Install anyway.

Already have CatCular from Google Play?

Uninstall it first: Android won't install this one on top of it.

  1. Unzip itRight-click the .zip, choose Extract All and open the folder.
  2. Open CatCular.exeIf Windows SmartScreen warns you, click More info and then Run anyway.
  3. Keep the folder togetherCatCular.exe needs CatCular.pck next to it. If you want a shortcut, create one instead of moving the .exe.
  1. Extract itUse your file manager, or this in a terminal:
    Terminal
    tar -xzf CatCular-0.9.7-Linux.tar.gz
  2. Open CatCular.x86_64It's inside the CatCular folder. If double-clicking doesn't open it, start it from the terminal:
    Terminal
    cd CatCular && ./CatCular.x86_64
  1. Unzip itOpen the .zip and drag CatCular to Applications.
  2. Open it oncemacOS will say it can't verify it. Close the warning without moving it to the Trash.
  3. Allow itGo to System Settings → Privacy & Security, scroll down and click Open Anyway.
  4. If it says it's damagedOpen Terminal, paste this, press Return and open it again:
    Terminal
    xattr -dr com.apple.quarantine /Applications/CatCular.app
